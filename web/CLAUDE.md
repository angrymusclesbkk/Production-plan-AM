# Angry Muscles — เว็บไซต์ร้านค้า

ไฟล์นี้คือคำสั่งประจำโปรเจกต์สำหรับ Claude Code อ่านทุกครั้งก่อนเริ่มงาน

## โปรเจกต์นี้คืออะไร

เว็บขายสินค้าของแบรนด์ Angry Muscles (ถุงเท้าสายเทรน เสื้อ ผ้าโพกหัว) ลูกค้าเป็นคนไทย เว็บภาษาไทยเป็นหลัก
เจ้าของร้านไม่ใช่โปรแกรมเมอร์ — อธิบายเป็นภาษาไทยง่าย ๆ บอกเสมอว่าต้องกดหรือพิมพ์อะไรต่อ และอย่าทำอะไรที่ย้อนกลับไม่ได้ (ลบข้อมูล, push ขึ้น production, เปลี่ยนค่า payment) โดยไม่ถามก่อน

สเปกเต็มอยู่ที่ `docs/SPEC.md` · ลำดับงานอยู่ที่ `docs/PROMPTS.md` · ข้อมูลสินค้าอยู่ที่ `data/products.json` · ต้นแบบหน้าตาอยู่ที่ `design/prototype.dc.html`

## Stack (ห้ามเปลี่ยนโดยไม่ถาม)

- Next.js (App Router) + TypeScript + Tailwind CSS
- โฮสต์บน Vercel
- ฐานข้อมูลและล็อกอินแอดมิน: Supabase (Postgres)
- **ลูกค้าไม่ต้องสมัครสมาชิก** (guest checkout) — ไม่มีระบบบัญชีลูกค้า มีล็อกอินเฉพาะแอดมิน · **อีเมลลูกค้าบังคับกรอก** ตอนชำระเงิน
- รับเงิน: Stripe Checkout ด้วย PromptPay (+ บัตร) — ถ้าเจ้าของร้านเลือก Opn Payments (Omise) หรือ 2C2P แทน ให้แยกโค้ด payment ไว้ในโฟลเดอร์ `lib/payments/` เพื่อสลับได้
- อีเมลแจ้งออเดอร์: Resend
- **ออเดอร์จะเป็น `paid` ได้จาก webhook ของ Stripe ที่ตรวจลายเซ็นแล้วเท่านั้น** ห้ามตั้งจากฝั่ง browser, จาก redirect, หรือจาก `checkout.session.completed` โดยไม่เช็ก `payment_status === "paid"` · ไม่มีระบบตรวจสลิป
- ห้ามใช้ LINE Notify (ปิดบริการแล้ว) — ถ้าจะแจ้งเตือนทาง LINE ให้ใช้ LINE Messaging API
- โดเมนจริง: **`angrymuscles.com`** (ใช้ `https://angrymuscles.com` ไม่มี www) — อ่านจาก env `NEXT_PUBLIC_SITE_URL` เสมอ ห้าม hardcode โดเมนในโค้ด เพราะ preview บน Vercel ใช้โดเมนอื่น · canonical, OG image, sitemap, robots และ product feed ต้องใช้ค่านี้
- เก็บ secret ทั้งหมดใน `.env.local` และ Vercel Environment Variables เท่านั้น ห้าม commit `.env*` ห้ามเขียน key ลงในโค้ด

## กฎเรื่องข้อมูลสินค้า (สำคัญมาก)

- ข้อมูลสินค้า ราคา สี ไซส์ สถานะการขาย ใช้จาก `data/products.json` (seed) และจากฐานข้อมูลหลัง Phase 2 เท่านั้น **ห้ามแต่งข้อมูลสินค้าเอง** ห้ามเดาเนื้อผ้า ไซส์ วิธีซัก ระยะส่ง หรือโปรโมชั่น
- **เว็บนี้ไม่นับสต็อกเป็นตัวเลข** ห้ามสร้างคอลัมน์ `stock`, ห้ามตัดสต็อก, ห้ามแสดงจำนวนคงเหลือ หรือข้อความแบบ "เหลือ 3 ชิ้น" — ใช้สถานะการขายด้านล่างเท่านั้น
- ข้อมูลที่ยังไม่มี ให้ใส่เป็น placeholder ในวงเล็บเหลี่ยม เช่น `[ใส่อัตราค่าส่ง]` แล้วบอกเจ้าของร้าน
- ไซส์ RUN / X’MAS / PRIDE เรียกว่า **"22–26 cm"** และ **"26–30 cm"** ห้ามแสดงเป็น S / M หรือ 22–27
  - 22–26 cm = เท้า 22–26 ซม. / EU 35–41 · 26–30 cm = เท้า 26–30 ซม. / EU 41–46
  - เท้า 26 ซม. หรือ EU 41 ใส่ได้ทั้งสองไซส์: ชอบกระชับ → 22–26 cm · ชอบสบาย → 26–30 cm
- OG / MAX REP / GRIP = Free Size รองรับความยาวเท้า 24–30 ซม. (ห้ามเขียน 36–43)
- สินค้าที่ **ไม่ขึ้นเว็บ**: Stickers, RUN HNY, RUN Halloween, OG Socks รุ่นเก่า, Cotton Bandana
- X’MAS และ PRIDE เป็น "RUN ลายพิเศษ" แต่แสดงเป็นการ์ด/หน้าสินค้าของตัวเอง (ราคา 380)
- variant ที่ `image` เป็น null ให้เว้นพื้นที่รูปว่างไว้ (ไม่ใส่รูปแทน ไม่ใส่รูปของสีอื่น)
- GRIP สีดำ (`AGOMR`) = ลาย **ONE MORE REP** (เจ้าของร้านยืนยันแล้ว) · MyOrder เรียกว่า "GRIP BC (BLACK)" ซึ่งเป็นชื่อหลังบ้าน ไม่ใช่ชื่อที่แสดงบนเว็บ — เว็บใช้ชื่อลายจาก `data/products.json` เท่านั้น

## สถานะการขาย (แทนระบบสต็อก)

แอดมินกดสลับสถานะได้เองจากหน้า `/admin` มี 2 ชั้น:

**ชั้นรุ่น** — `products.published` (true/false)
`false` = ปิดทั้งรุ่น ไม่ขึ้นเว็บเลย: ไม่อยู่ในหน้ารวมสินค้า ไม่อยู่ใน `sitemap.xml` ไม่อยู่ใน product feed และ `/products/[slug]` ตอบ 404

**ชั้นตัวเลือก** — `variants.availability` 3 ค่า (แยกตามสี + ไซส์)

| ค่า | เรียกในเว็บ | ลูกค้าเห็นอะไร | ปุ่ม |
|---|---|---|---|
| `on_sale` | พร้อมขาย | เลือกได้ปกติ | **ใส่ตะกร้า** |
| `preorder` | รอพรีออเดอร์ | เลือกได้ มีป้าย "พรีออเดอร์" | **พรีออเดอร์ทาง LINE** |
| `unavailable` | ยังไม่พร้อมขาย | เลือกได้ มีป้าย "ยังไม่พร้อมขาย" | **สอบถามทาง LINE** |

กฎ:

- `preorder` และ `unavailable` **ห้ามใส่ตะกร้า ห้ามไปหน้าชำระเงิน** ทั้งคู่จบที่ LINE ต่างกันแค่ป้ายและข้อความบนปุ่ม
- ทั้งสองสถานะ **ยังแสดงในเว็บและเลือกได้** (ไม่ซ่อน ไม่เทาทึบจนกดไม่ได้) เพราะลูกค้าต้องกดเลือกสี+ไซส์ก่อน จึงจะรู้ว่าต้องแจ้งอะไรใน LINE — จะซ่อนของได้เฉพาะปิดทั้งรุ่นด้วย `published = false`
- ปุ่ม LINE ทุกปุ่มในเว็บลิงก์ไป `https://lin.ee/SNUS5D2` (เปิดแท็บใหม่) และใต้ปุ่มแสดงข้อความให้ลูกค้าคัดลอกไปพิมพ์เอง: "แจ้งในแชทว่า: {ชื่อสินค้า} สี {สี} ไซส์ {ไซส์} จำนวน {n} {หน่วย}"
- ปุ่มสีที่ทุกไซส์ไม่ใช่ `on_sale` → ขีดแดงทับวงกลมสี (เหมือนต้นแบบ) แต่ยังกดได้
- ถ้าทุกตัวเลือกของรุ่นไม่ใช่ `on_sale` → หน้าสินค้าไม่ต้องมีปุ่มใส่ตะกร้าเลย เหลือปุ่ม LINE เดียว
- JSON-LD และ product feed แมปสถานะเป็น: `on_sale` → `InStock` · `preorder` → `PreOrder` · `unavailable` → `OutOfStock`
- หมายเหตุ: `design/prototype.dc.html` มีแค่ 2 สถานะ (ธง `out: true/false`) ใช้ดูหน้าตาและข้อความได้ แต่เว็บจริงต้องมี 3 สถานะตามตารางด้านบน

## หน้าตา (Brand)

- สี: แดงแบรนด์ `#D12129` (แดงเข้มสำหรับตัวหนังสือบนพื้นชมพู `#B3121F`) · หมึก `#17120F` · พื้นครีม `#FFFBF7` · ชมพูพาสเทล `#FFD6E2` · เขียว LINE `#06C755` (ตัวหนังสือบนปุ่ม LINE ใช้สีหมึก ไม่ใช่สีขาว เพราะ contrast ไม่ผ่าน)
- พื้นการ์ดตามหมวด: วิ่ง `#FFE3EB` · พิลาทิส `#ECE6FF` · ใส่ทุกวัน `#FFF1D6` · เสื้อ/ผ้าโพกหัว `#E3F5EC` · ถ้าสินค้ามี `image_bg` ให้ใช้สีนั้นแทน
- ฟอนต์: หัวข้อ Kanit (600–800) · เนื้อหา Anuphan (400–600) จาก Google Fonts ผ่าน `next/font`
- สไตล์: ขอบเส้นหมึกหนา 2.5px มุมโค้ง 22px ปุ่มทรงแคปซูล เงาแบบ offset (`6px 6px 0 #17120F`) ตอน hover — ขี้เล่นแบบสติกเกอร์ ไม่ใช้ gradient ไม่ใช้ emoji
- โลโก้: `public/images/brand/logo-red.webp` (พื้นสว่าง) · `logo-white.webp` (พื้นเข้ม)
- ลิงก์ช่องทางของร้านอยู่ใน `data/products.json` คีย์ `social` (tiktok, instagram, shopee) ใช้ใน footer ทุกหน้าและใน `sameAs` ของ Organization JSON-LD — ห้าม hardcode ในโค้ด ห้ามเดาลิงก์เพิ่มเอง
- ต้องใช้งานได้ดีบนมือถือก่อน (ลูกค้าส่วนใหญ่มาจาก IG / TikTok) · ปุ่มสูงอย่างน้อย 44px · ตัวหนังสือ contrast ผ่าน WCAG AA

## SEO

- ทุกสินค้ามีหน้าของตัวเองที่ `/products/[slug]` (ต้นแบบใช้ป๊อปอัป แต่เว็บจริงต้องเป็นหน้าแยกเพื่อให้ Google เก็บได้)
- หน้าเว็บ render ฝั่ง server (Server Components / SSG) ให้ข้อความและราคาอยู่ใน HTML ตั้งแต่แรก
- ทุกหน้ามี title / description ภาษาไทย, OpenGraph image, canonical URL
- หน้าสินค้ามี JSON-LD `Product` + `Offer` (ราคา THB, availability ตามสถานะการขาย — ดูหัวข้อสถานะการขาย)
- มี `sitemap.xml`, `robots.txt` และ product feed สำหรับ Google Merchant Center
